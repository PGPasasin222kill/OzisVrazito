# Meowdoku Screen Solver

Aplicație Android pentru afișarea pozițiilor pisicilor peste joc, folosind captură de ecran autorizată de utilizator. Detectează automat dimensiunea tablei și colorează marcajele fără a apăsa pe joc.

## APK
Deschide GitHub Actions → `Build Meowdoku Android APK` → cea mai recentă rulare reușită → `Artifacts` → `Meowdoku-Screen-Solver-APK`.

Această modificare documentează pașii de instalare și declanșează un nou build pentru refacerea APK-ului șters. Nu modifică algoritmul aplicației.
